# Проект с микросервисной архитектурой

## Для запуска с помощью compose.yaml
1. Необходимо установить сертификаты разработчика:   
   1.1. В корневой папке проекта выполнить две команды:   
        `dotnet dev-certs https -ep certs/dev-cert.pfx -p <YOUR_PASSWORD>`   
        `dotnet dev-certs https --trust`
2. Необходимо создать .env файл, опираясь на .env.example и заполнить значениями
3. Запустить приложение из корня `docker-compose up --build -d`

## Запуск отдельных сервисов локально
1. Необходимо заполнить `secrets.json` своими значениями
2. В Docker или локально запустить сервисы, от которых зависит запускаемый сервис
3. Запустить сервис
